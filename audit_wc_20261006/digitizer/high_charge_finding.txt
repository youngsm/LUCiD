SK_WAND high-charge PMT response omission: confirmed local physics gap
===================================================================
This addendum supersedes findings.txt's earlier statement that no fresh
production occupancy witness was available. No campaign-wide large error
has been established, and no production code has been modified.

Physical reference, independently inspected
-------------------------------------------
Abe et al., Calibration of the Super-Kamiokande Detector, arXiv:1307.0162v2,
section3.1.7, printed pages22-24, Figure19:
https://arxiv.org/html/1307.0162v2#S3.SS1.SSS7
https://arxiv.org/pdf/1307.0162
Local preserved PDF: refs/SK_calibration_1307.0162.pdf
Local inspected Figure19: refs/sk_id_nonlinearity_fig19.png

The measurement normalizes each tube near30PE. It reports ID-PMT response
linear within1% below/near200PE and deviation exceeding10% above1000PE.
Figure19 gives the sign: high-charge compression, observed/expected below1.
The reported effect belongs to the20-inch ID PMT/anode response; QBEE
readout is separately linear to1%. These are R3600-05(A) ID PMTs, not HK
box-and-line tubes. This identifies relevant sensor physics for SK_WAND's
SK20-inch response, though transferring an exact calibration between SK
periods also requires matching gain, high voltage, and pulse conditions.

The old ATM electronics'450pC range is a separate effect from PMT
nonlinearity. The preset name 'ski' alone does not justify clipping at a
chosen ATM range: LUCiD advertises SK-like detector electronics, and a
specific hardware epoch has not been established. Do not combine a PMT
nonlinearity correction with an assumed ADC ceiling without that choice.

The production source explains this: _sample_spe_charge in digitizer.py
lines310-333 sums independent single-PE draws with count-independent

No intensity-dependent transfer function is present anywhere in that path.

Minimal physically defensible fix suggestion
--------------------------------------------
Add a calibrated SK PMT charge-response curve to the digitizer model and
apply its transfer function to the unsaturated analog charge before final
readout/discrimination, using an explicitly matched pulse/gain regime.
Schematically at apply_readout_resolution's charge boundary:

    q_linear = _sample_spe_charge(pe_true, model['spe'], rng)
    q_reco = calibrated_sk_transfer(q_linear, model['charge_response'])

The curve should map expected linear charge to measured mean output using
the SK average calibration or a directly measured R3600 response, with
interpolation and a declared validated range. Preserve low-charge SPE
behavior; keep any electronics saturation separately parameterized. Timing
must use the appropriate calibrated pulse charge after response is modeled.
For pulses spread across much of200ns, validate the integrated-charge
approximation or apply the nonlinearity at pulse level before summing.

No numerical replacement curve is supplied by this audit because the
paper's figure and prose do not provide enough precision to assert a
calibrated1190PE correction. An arbitrary10% multiplier or hard clip would
not satisfy the requested physical correctness. A regression should verify
measured response ratios at several published/calibrated pulse intensities,
including the linear regime and the high-charge compression region.
