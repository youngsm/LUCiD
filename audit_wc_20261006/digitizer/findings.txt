Physical validation gaps, not claimed new large bugs
----------------------------------------------------
Detailed independently checked sources are in refs/physical_reference_review.txt.

1.No saturation/nonlinearity model is applied to the summed charge.
  SK calibration arxiv1307.0162 section3.1.7 measures >10% response deviation
  beyond1000PE and approximate linearity only through200PE. A production
  occupancy scan later found one1190PE digit in10 ordinary bomb events.
  See high_charge_finding.txt for the executed response probe and production
  occupancy: this digit holds0.413% of cohort charge. Exact raw replay on
  milano job39970809 confirms1152PE arrive within1ns, so prompt optical
  reachability is established. Its exact anode-charge correction still
  requires a calibrated response matched to the detector's gain/period.
  Appropriate eventual fix: calibrated integrated-charge response curve and
  explicit electronics range for the intended detector era, not an arbitrary
  clipping level. This is a scientifically relevant gap, not a certified
  high-severity finding in the present audit.

2.A WCSim dark-rate conversion factor1.367 is NOT a proven physical fix.
  Its PMT20inch source explicitly calls4.2kHz a PRE-threshold SK-I rate and
  gives measured post0.25PE rate3.4kHz. WCSim's extra conversion and these
  provenance statements are inconsistent. LUCiD3.227kHz is about5% below
  that3.4kHz measurement. Do not report a23% physical loss merely by treating
  raw4.2kHz as a measured post-threshold target.

3.A real SK timing PDF is asymmetric and channel-dependent; the Gaussian
  WCSim-style width does not prove exact real detector timing. Missing
  afterpulse/prepulse physics and analog threshold-crossing causality are
  calibration gaps, but no new large in-scope production consequence was
  demonstrated. The documented charge-spectrum shape is user-accepted.

4.The independent trigger interval oracle used continuous times. Exact ties
  at t and t+window are implemented with arrivals before expirations, i.e.
  inclusive endpoint counting. This differs from the docstring's half-open
  trailing window; no campaign-large impact is claimed for a boundary/TDC
  convention difference.

5.Empty detected-physics streams produce no dark-only event. The production
  interface is event-conditioned, not a complete continuous detector DAQ.
  The dark envelope depends on detected light and its padding, so extremely
  rare self-sustaining noise gates can reach its edges. Magnitude was not
  established; this is not the formerly fixed deterministic padding defect.

Explicitly excluded/accepted here: late100us/10us light cuts, the charge-
spectrum shape, realistic-mode TTS, supernova chunks, direct CLI/EventID/
input-vertex truth issues, c/1.33, endpoint search, unpolarized scattering,
clamped QE wavelength and sphere PMTs. No production code modified.
