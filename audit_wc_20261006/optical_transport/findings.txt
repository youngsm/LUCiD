Independent physical checks

check_transport_physics.py evaluates the actual production photon-step code using
262,144 independent keys. Reference probabilities derive from independent exponential
hazards, not from repository test expectations. Let s=1/L_R+1/L_M, a=1/L_A and D be
distance to a boundary, with boundary reflectance R. Then

  P(reach boundary)=exp(-sD)
  P(nonreflected and survive)=(1-R)*exp(-(s+a)D)
  P(reflected and survive)=R*exp(-(s+a)D)
  P(scatter and survive)=s/(s+a)*(1-exp(-(s+a)D))
  E[scatter distance | scatter before D]=1/s-D/(exp(sD)-1)

The checks use D=20m, L_R=30m, L_M=50m, L_A=40m, R=.25, g=.95.
They also check the Rayleigh CDF F(mu)=1/2+3mu/8+mu^3/8, second moment2/5,
HG mean g, HG second moment(1+2g^2)/3, and Lambertian hemisphere mean cosine2/3
and second moment1/2 at both axial and oblique reference directions. Surviving
and absorbed scattered photons independently retain the expected angular mean.

The k2 reuse for truncated scatter distance and reflect/nonreflect sampling is
not a confirmed defect: those draws affect mutually exclusive branches and the
branch selector uses independent k1. Mie versus Rayleigh uses independent k5;
absorption uses independent k6; reflected direction uses k4. The local-to-global
rotation uses frame.T, consistent with basis vectors stored as rows. The inward
reflection hemisphere uses the normal with its sign consistent with the geometric
interface. The corrected scalar QE/(1-R0) convention is consistent with external
incident-photon QE; this does not independently establish QE table provenance or
whether that table includes electron collection efficiency.

Physical-model limitations, not demonstrated large implementation bugs

1. Asymmetric-scattering law: the cited SK calibration paper p31 uses density
   p(mu)=2mu for0<=mu<=1, hence E[mu]=2/3 and zero backward scattering. LUCiD's
   water config uses HG g=.95. check_transport_physics.py records its mean and
   backward fraction. A minimal diagnostic is:

     u=(jnp.arange(262144)+.5)/262144
     mu=hg_sample_cos_theta(u, .95)
     print(mu.mean(), jnp.mean(mu<0))

   This demonstrates a difference from that SK fit model, not that HG is impossible
   physical Mie scattering. The asymmetric rate at400nm is about1e-4/m, so this
   cannot be presented as a huge total-yield defect without event-level evidence.
   To reproduce that specific SK model, introduce a water-specific asymmetric phase
   sampler mu=sqrt(u), including the corresponding density where AD scores are used;
   do not globally replace HG for media which genuinely use HG.

2. Uniform water and scalar reflectance: the current reference is independent of
   position/time and scalar_mix has angle/wavelength-independent reflection rates.
   The SK calibration paper pp33--35 describes measured vertical absorption
   dependence and angle/wavelength-dependent surface calibration. Exact real-SK
   equivalence is therefore not established. These are physical calibration/model
   gaps, not proven new production coding mistakes. The user-accepted constant
   light speed, unpolarized scattering and endpoint PMT search are not reported
   as bugs here.
