Packaging source/dependency review, 6 October 2026

Publication scope: report, source tests, proposed/tested patches, compact results
and provenance. Large raw evidence, executables, caches, environments and sandbox
directories are regeneration products, not files to push. The package inventory
must distinguish a file present in the working tree from a file actually shipped.

1. Runtime dependencies
   The previous Geant4 wrapper lived outside this repository and used an external
   bind-mount sandbox. Its mechanism is now bundled as packaging/run_photonsim.sh
   and make_rootfs.sh. packaging/RUNTIME.md records exact CVMFS dependencies,
   interpreter inheritance, overrides and preparation order. This removes that
   script dependency, not the host Apptainer/CVMFS/LCG dependency. No host identity
   files should be shipped with a generated rootfs.

   The baseline Python environment inherits a separate conda environment through
   include-system-site-packages=true. Copying its venv is not sufficient. The
   packaging validation captures a visible-package inventory; the separate
   runtime_jax0438/requirements-resolved.txt remains the pinned 0.4.38 inventory.
   Preserve that runtime distinction in every result and setup description.

2. Historical paths and preparation
   Most old sbatch files still hardcode checkout, uv, interpreter and wrapper
   paths. The new wrapper is relocatable; the full launcher collection is not yet
   portably validated. Prefer a clearly labelled launcher-copy generator which
   substitutes only those known literal site prefixes with configured values,
   leaving original evidence files unchanged. Generated copies still need a
   small Slurm smoke test. Shell parameter expansion is not performed inside
   #SBATCH directives, so output/account paths need actual rewritten text or
   submission command options.

   Regenerate macros/commands after relocation: saved files can embed absolute
   fixture paths. Several analysis-only launchers need raw files produced by
   earlier jobs. RUNTIME.md lists major dependencies. primaries/run_spin.sbatch
   now calls prepare.py before prepare_spin.py, and its missing-polarization
   regression validates event count, GENIE entry IDs and PDGs to reject fallback.

3. Links and source provenance
   Read-only review found every local Markdown link in REPORT.md and existing
   audit .md notes resolves in the current workspace; report anchors match.
   All 26 files named by the GENIE source manifest exist. No absolute local
   Markdown links or incompatible :line anchors were found. Repeat against the
   actual publication inventory after excluding raw data; existence now does not
   guarantee inclusion in the branch.
